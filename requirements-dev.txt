#   python scripts/patch_phacc_ha2026_11.py

# .github/workflows/ci.yml, "Override Home Assistant for the pytest jobs").
# Remove the override and the patch script once
# pytest-homeassistant-custom-component ships a release bundled with Home
# Assistant 2026.11.

# override Home Assistant as described above.

# Integration dependencies (mirrors manifest.json requirements).
# [pymodbus] provides the pymodbus stack, [tmodbus] provides ``tmodbus`` and
# ``serialx``. The HA ``modbus`` component (2026.10/2026.11) imports
# ``modbus_connection.tmodbus`` at load time, so the test environment must be
# able to import ``homeassistant.components.modbus``; without the [tmodbus]
# extra the guarded imports in ``modbus/connection_manager.py`` degrade to
# ``None`` and the provider tests cannot exercise the real import path.
modbus-connection[pymodbus,tmodbus]>=4.10
